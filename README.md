# AUREX DJ v0.5 — prueba

Novedades: navegación por cuatro secciones, guía paso a paso para DDJ-FLX4, cuatro tiempos de referencia derivados de CUE manuales, selector de 4/8/16/32 compases y efectos orientativos.

Limitación: no se analiza audio de Spotify ni se infiere fraseo. Los marcadores iniciales requieren verificación auditiva; los finales se calculan con tempo estable. La guía no equivale a una mezcla comprobada.

Instalación: exporta antes copia JSON desde v0.4; sube los seis archivos a la raíz de GitHub Pages. Mantén la misma URL de Spotify OAuth.
